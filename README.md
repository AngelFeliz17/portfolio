# Modern Portfolio Website

A beautiful, modern portfolio website built with React and Tailwind CSS.

## Features

- 🎨 Modern and responsive design
- ⚡ Fast and optimized with Vite
- 🎭 Smooth animations and transitions
- 📱 Fully responsive for all devices
- 🎯 Clean and maintainable code

## Sections

- **Hero**: Eye-catching introduction with call-to-action buttons
- **About**: Personal information and statistics
- **Skills**: Showcase of technologies and tools
- **Projects**: Featured projects with links to code and demos
- **Contact**: Contact form and information
- **Footer**: Social links and copyright

## Getting Started

### Prerequisites

- Node.js (v16 or higher)
- npm or yarn

### Installation

1. Install dependencies:
```bash
npm install
```

2. Start the development server:
```bash
npm run dev
```

3. Open your browser and visit `http://localhost:5173`

### Build for Production

```bash
npm run build
```

The built files will be in the `dist` directory.

### Preview Production Build

```bash
npm run preview
```

## Customization

1. **Personal Information**: Update the content in:
   - `src/components/Hero.jsx` - Name, title, and social links
   - `src/components/About.jsx` - About section content
   - `src/components/Contact.jsx` - Contact information

2. **Projects**: Edit the projects array in `src/components/Projects.jsx`

3. **Skills**: Modify the skills array in `src/components/Skills.jsx`

4. **Colors**: Customize colors in `tailwind.config.js` or directly in components
